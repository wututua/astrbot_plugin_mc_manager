填写你希望发送到群聊的文字。保留 {变量} 可以插入玩家、服务器和操作结果。

      

        
TPS 查询方式与指令
每台服务器可独立选择服务端原生 TPS 或 spark 性能指标，也可自定义查询指令。原生模式完整返回服务端回复；只有 spark 使用变量和模板。原生命令是否可用取决于服务端核心。

        
spark TPS 回复

          
该按钮仅恢复 spark 模式服务器的查询命令和默认 TPS 模板。CPU 变量不带 %，Tick 耗时单位是毫秒。

          

          
查看 spark TPS 变量表
占位符含义单位示例
med 是中位数；P95 是第 95 百分位。{result} 和 {tps_raw} 保留原始响应。

          

          
spark 回复为空时如何采集
包内的 companion/astrbot-spark-agent.jar 可通过 Java 启动参数加载，每 2 秒采集一次。TPS 数据来源 auto 会优先读取有效的本地报告；安装步骤在 companion/README.md 中。

        

      

      
高级 JSON 编辑
