    帮助菜单
    
        
    
        
    
          
    群与游戏消息互通
    默认关闭。开启下方群绑定会同时开启总开关；总开关可暂停所有群的互通。仅在关联服务器与群之间转发。
    
          
    群绑定与转发范围
    每组可选择转发方向与事件。开启后在每个实际群发送一条普通文字或 /mc 以记录会话。游戏事件读取服务端新增日志，日志路径与编码可在服务器编辑窗口修改。
    
          
    消息格式
    群 → 游戏模板支持 § 染色码，如 §b 青色、§l 加粗、§r 重置。变量：{server} 服名、{server_id} 服ID、{group} 群号、{player} 玩家、{nickname} 群昵称、{user} 用户ID、{message} 正文、{event} 类型。
    
        
    
        
    
          
    全部消息模板
    回复、错误、状态明细、TPS 摘要、日志和游戏广播均可修改。留空可隐藏该段文字；完整回复留空则不发送消息。
    
          
    
          
    点击变量可插入光标处；{{ 和 }} 表示普通花括号。修改后点击顶部“保存并生效”。帮助、互通和 TPS 页的专用编辑器同步显示当前输入。
    
          
    
        
    
        
    
          
    TPS 查询设置
    按服务器选择查询指令和输出格式。所有支持的 TPS 数据都可填入变量模板；未知内容保留原文。
    

          
    TPS 自定义变量模板
    
            
    完整指标、状态和查询变量见“变量文档”，支持搜索、分类和模板预览。
    
            
    spark 回复为空时
    控制台有 spark 报告但 RCON 为空时，可在上方展开“新增日志回读”，开启并设置 logs/latest.log。只读取本次命令之后新增的报告，无需 Java 采集器或额外 JVM 参数。执行 spark tps 时自动适用；不会补造缺失指标。
    
          
    
        
    
        
    
          
    查询与状态变量
    所有支持的 TPS 查询结果都可将实际返回数据转成变量，使用可编辑的机器人模板。按数据格式查看可提供的字段；状态和玩家回复另支持人数、来源和缓存。
    
            
    
            
    
            
    手机可左右滑动变量表查看完整说明与示例。
    
            
    变量表 · 点击变量插入预览模板
    变量分类 / 适用含义单位示例
    
            
    CPU 变量不含 %，请在模板加 %；耗时单位为 ms。缺失值显示“暂无数据”，不会填充 0 或 20。RCON 不可用时显示失败，未知指标不会填为正常值。
    
          
    
          
    模板预览
    提供通用、spark、Paper/Spigot、Forge/NeoForge、原版和自定义输出初始模板。每个样例只填它实际有的数据，不连接服务器；确认预览后直接保存生效。
    只支持 {变量}，字面花括号写 {{ 和 }}；不支持属性访问、表达式或 :.2f 格式。预览编辑只有点击“保存当前模板”后才会生效。
    
        
    
        
    高级 JSON
    修改后可直接保存，也可先预览到表单。
