spark TPS 回复

该按钮会设置本配置中所有服务器的查询命令为 spark tps，并恢复默认 TPS 回复。编辑后点击“保存并生效”。CPU 变量不含 %，Tick 耗时单位是毫秒。

查看 spark TPS 变量表
占位符含义单位示例

med 是中位数；P95 是第 95 百分位，95% 的样本不超过该值。缺失值显示配置的占位文字。{result} 和 {tps_raw} 保留原始输出。

spark 回复为空时如何采集

包内附带 companion/astrbot-spark-agent.jar。把它复制到服务端共同父目录，在每台服的 Java 启动命令中添加 -javaagent:实际路径/astrbot-spark-agent.jar，并从对应服务端目录启动。采集器会读取已安装的 spark API，每 2 秒生成本服 .astrbot-spark-tps.txt。默认 tps_source=auto 优先读取有效报告；超过 spark_file_max_age 的旧数据会拒绝使用。具体步骤在安装包的 companion/README.md 中。

菜单与消息模板怎么修改

commands.add 可以改为 add，commands.prefix 可以改为 minecraft。messages.help 是帮助菜单；messages.restart_success 与 messages.restart_failed 是群内重启广播。常用占位符：{prefix}、{player}、{id}、{server}、{result}、{error}、{seconds}、{entries}、{sync}。所有模板可在插件配置页单独编辑。
