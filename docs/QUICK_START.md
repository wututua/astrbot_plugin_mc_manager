# 快速上手

服务端已开启 RCON、AstrBot 能读写服务端目录时，通常只需要填写 **目录和群号**。首次安装会自动打开快速配置，不需要逐个填写服务器 ID、端口、密码和 UUID 模式。

## 1. 填写目录与群号

打开 **插件详情 → Minecraft 管理面板**，在“快速配置”填写：

- **服务端目录**：共同父目录，例如 `D:/Minecraft`；也支持直接填写一台服务端所在的目录。
- **群号 / 群 ID**：多个群用逗号分隔。

只有一个消息机器人时会自动选择；有多个时请选择要使用的机器人。没有可选项时，填写群内 `/sid` 返回的 Bot ID。

## 2. 扫描并确认服务器

点击 **扫描并读取配置**。页面从 `server.properties` 读取 RCON 端口、密码、`online-mode` 和白名单开关，默认勾选新发现且参数齐全的服务器；只有一台已配置服务器可用时也会自动勾选。

未开启 RCON、密码缺失、重复端口、无法读取等问题会列在对应服务器下，不会伪装成可用。白名单未开启时会明确提示，需要自行核对游戏入服限制。参数文件被修改后请重新扫描。

扫描仅检查指定目录及最多两级子目录，最多 64 个服务端，不跟随子目录链接，不修改 `server.properties`。密码不会返回浏览器，扫描结果只在后台短期保留，10 分钟后失效；重新加载页面不会恢复未提交的选择。

## 3. 保存并使用

核对勾选范围，点击 **保存并完成配置**。服务器与群绑定一次保存，内部 ID 自动生成，随后进入对应群配置的服务器概览。新导入服务器默认开启 TPS 指令自动探测，使用可编辑的初始回复模板。

在绑定群里发送 `/mc`，即可查看常用菜单并登记广播会话。已保存服务器的连接参数、自定义指令、白名单归属和管理员配置会保留。为现有群增加服务器时请使用该配置的完整群号列表，避免影响其他共用配置的群；属于不同配置组的群不能自动合并。

## 手动设置与容器

需要特殊端口映射、密码环境变量或代理转发 UUID 时，展开 **手动配置**。快速配置的“远程地址 / 容器设置”可指定新服务器共用的 RCON 地址；不同地址或映射端口请使用手动添加。

手动表单仍自动生成 ID、分配未占用的默认 RCON 端口；单台服务器会自动勾选。弹窗可测试只读连接并直接保存，也可取消。已有配置跨共同父目录迁移应手动处理，快速配置不会改变既有服务端路径。详细准备与权限见[部署指南](DEPLOY.md)。

## 日常指令

```text
/mc 添加 Steve
/mc 我的
/mc 玩家
/mc tps
/mc 移除
/mc 修改 Alex
/mc 帮助 all
```

`移除` 和 `修改 新名字` 只会自动选中自己唯一的一条白名单；有多条时会列出编号供选择，不会任选一条，也不会选中其他人的条目。显式写编号或原名的方式仍可使用。管理员在仅绑定一台服务器的群中可用 `/mc 重启`；多服时需要选择服务器或明确写 `all`。

默认 `/mc` 菜单只列常用指令，完整菜单用 `/mc 帮助 all`。已有自定义菜单会保留；想采用精简默认菜单，可在“回复与广播”搜索 `help` 并单独恢复默认。

## 常见调整

- **TPS**：在“TPS 设置”点击 `spark tps`、`tps`、`forge tps`、`tick query` 等快捷按钮填入指令，再保存；不会同时切换其他设置。
- **回复文字**：在“回复与广播”搜索原文或模板名；默认先显示 8 项，可继续展开。变量文档中的样例可以预览后直接“保存当前模板”。
- **消息互通**：开启目标群的互通开关，会同时开启总开关；总开关可统一暂停全部已开启的群。保存后，在每个实际群发送 `/mc` 登记会话。
- **修复连接**：服务器概览可直接点击“配置”或“修复连接”，不用再从设置列表寻找对应服务器。
- **移除服务器**：一次确认后，自动清理相关群绑定并保存；仅有这台服务器的组会移除绑定，服务端文件与历史条目/日志保留。

弹窗只提供“保存并生效”和“取消”，不再提供暂存入口；取消不保留本次弹窗修改。模板预览直接点击“保存当前模板”生效。普通设置修改后从顶部保存。保存失败会留在当前输入处，修正问题后重试；删除、重启、恢复备份和批量修改仍保留必要的确认与权限检查。
