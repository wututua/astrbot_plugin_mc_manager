# 环境验证矩阵

框架支持范围为 AstrBot >=4.28.0,<5、Python 3.12+。本表区分已执行的自动化检查与尚需实际部署验证的组合，当前插件无需附带的 Java 采集器或开发机 JDK；Minecraft 服务端自身的 Java 要求由核心决定。

| 范围 | 已有验证 | 边界 |
| --- | --- | --- |
| AstrBot 4.28.0 / 4.29.0 | 正式发布源码的接口、命令、安装器、网页 SDK 与插件回归 | 隔离调用与模拟消息平台，不是完整生产 AstrBot 进程 |
| AstrBot 4.28.1 / 4.28.2 | 历史接口检查 | 本轮完整回归以验证记录为准 |
| Python 基线回归 | Windows / Python 3.12、两套官方 SDK 各 519 项通过，0 跳过；402 项模板与自动配置一致 | 详细覆盖见[验证记录](VALIDATION.md#未发布自动读取服务端与一次完成群绑定) |
| 本轮自动配置网页 | 两套官方 SDK 的首次进入、扫描、一次保存群绑定、敏感值不传页面、失败重试及正确配置组导航通过 | [自动配置验证记录](VALIDATION.md#未发布自动读取服务端与一次完成群绑定) |
| 网页 | Chromium、320/390/768/1024/1440 宽度、官方两套 SDK | 后端和父页面使用模拟数据；备份等另有真实 SQLite/官方 Web API 集成检查 |
| Windows / Linux | GitHub Actions 四个组合各 262 项测试通过，0 跳过 | Linux 实际镜像 Ubuntu 24.04；框架接口和模拟连接验证 |
