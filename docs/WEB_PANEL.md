# 网页管理使用说明

v1.1.0 要求 AstrBot >=4.28.0,<5，提供完整的可视化配置表单，大部分日常操作都可以在 AstrBot 插件详情页里的 Minecraft 管理面板中完成。

## 入口

在 AstrBot 插件管理中打开 **Minecraft 群服管理 → Minecraft 管理面板**。打开“配置与菜单”，可以看到六个配置分类。页面使用 AstrBot 后台身份认证，只有登录管理后台的人员可以使用管理功能。

## 首次设置

1. “服务器与群聊”填写服务端共同父目录，例如 `D:/Minecraft`。
2. 点击“添加服务器”，填写唯一 ID、显示名称、相对文件夹、RCON 地址和独立端口。填写密码或密码环境变量，选择 UUID 模式和 TPS 数据来源。
3. 点击“添加群聊”，选择消息平台实例，填写群号、管理员用户 ID，再勾选本群服务器。管理员账号每行一个或逗号分隔。
4. 点击弹窗的“加入配置草稿”，然后点击页面上方“保存并生效”。保存完成后立即应用，不需要再次重载插件。
5. 在对应群发送一次 `/mc`，让插件记录群广播会话；或在群编辑表单中填写已有的广播会话。

消息平台下拉项显示实际实例 ID。若实例未运行或没有列出，可选择“手动填写其他平台实例 ID”；没有可用平台列表时直接输入。目标群发送 AstrBot 的 `/sid` 后，回复中的 Bot ID 可用于填写平台实例 ID。

同一服务器只能属于一个群；添加群时其他群占用的服务器会禁用。一个群下的服务端需要使用同一 UUID 身份模式。白名单条目归属按群成员的账号记录。

## 页面中可以管理什么

| 页面 | 可操作内容 |
|---|---|
| 服务器 | 当前群服务器状态、在线玩家、TPS、单服重启 |
| 白名单 | 添加、修改玩家名、移除、重试同步、导入现有条目 |
| 操作日志 | 按群查看，按操作者账号筛选，分页 |
| 配置：服务器与群聊 | 服务器的增改移除、群绑定的增改移除、管理员账号、每人条目上限 |
| 配置：常规设置 | 每页数量、同步间隔、RCON 超时、重启超时、检查间隔、游戏内广播开关 |
| 配置：指令与菜单 | 主指令、各子指令别名、帮助菜单文本、菜单预览 |
| 配置：回复与广播 | 添加/移除/修改回复、列表格式、玩家/状态回复、日志格式、重启成功与失败广播 |
| 配置：spark TPS | TPS 模板、缺失值、数据有效期、警告/失败模板、变量表、恢复 spark 默认配置 |
| 配置：高级 JSON | 批量导入与编辑完整配置，并应用到表单 |

## 修改、保存和密码

表单和弹窗修改先进入页面草稿，未保存时会显示“有未保存的修改”。切换群或功能页、刷新服务器状态都不会覆盖草稿。关闭或刷新整个浏览器页面时，浏览器会对未保存的修改提示离开确认。

“重新载入”用于恢复后台保存的版本。已有草稿时会先确认是否丢弃。高级 JSON 修改点击“应用到表单”后会更新可视化表单，最终仍需点击“保存并生效”。从高级 JSON 切换回表单时也会先检查 JSON 格式。

已保存的 RCON 密码不返回明文：编辑弹窗中密码输入为空，留空即保留。输入新密码可以替换；显式勾选“清除已保存的密码”才会清除。高级 JSON 中 `__KEEP__` 同样表示保留，新增服务器不能把它当作实际密码填写。

如果多个后台页面同时修改配置，旧页面保存时会收到冲突提示，当前草稿保留；重新载入最新配置后再修改并保存。

## 群和服务器身份保护

已保存的群配置 ID、平台 ID 和群号在表单中只读，防止历史白名单和日志被误分配给其他群。管理员账号、服务器选择和条目上限仍可修改；要添加不同群，请创建一个新的群绑定。

移除群绑定只停止该群的插件功能，历史白名单、归属、编号与日志保留。服务器有历史归属后，不允许直接跨群改绑。已有群引用的服务器需要先修改或移除群绑定，才能从配置中移除该服务器；页面不会删除 MC 文件或服务器进程。

新增服务器/群 ID 会避开历史占用的 ID。服务端运行文件夹、RCON 密码环境变量和自动重启脚本仍需要在实际服务器上准备。

## 更新已有插件

导入 v1.1.0 后重载插件并刷新管理页面。包内同时提供 pages 与 views 入口，分别供对应版本发现；旧服务器、群绑定和模板会自动填入表单，插件数据目录中的归属与日志继续保留。
