## 重点行为

| 范围 | 已覆盖行为 |
| --- | --- |
| 白名单 | 首次并集合并、冲突与损坏保护、固定编号、归属、改名、删除持久化、不自动复活旧条目 |
| 群隔离 | 平台实例与群号隔离、跨群服务器选择拒绝、管理员范围 |
| 权限 | 普通用户不得操作他人条目、严格布尔管理身份、事件角色复核、异常配置、API Key 降权 |
| 写入权限 | 按编号/玩家名/自定义别名核对归属，等待 UUID 查询后 SQL 再检查归属变化 |
| 在线探测 | 启动/重载/有效配置保存后自动探测、周期离线与恢复、慢连接并行、取消与恢复 |
| 改绑 | 删除群释放服务器、逐服转组、同平台改群号、跨平台清空归属、旧广播清理、迁移回滚 |
| 生命周期 | 配置错误保留修复页面、密码脱敏、保存立即应用、失败回滚、卸载等待进行中的操作 |
| RCON | 认证、拆包、多包、UTF-8、响应界标、超时、停止后的断线 |
| 重启 | 旧连接断开、新连接连续两次查询、超时/失败、监控中断恢复、广播队列重试 |
| spark | 19 个指标、时间窗口映射、缺失/非法值、空响应、本地报告路径和有效期 |
| 打包 | 必填元数据、版本一致、原生安装器解压、单一页面发现、pages/views 一致、许可证和图标 |

权限修复中的“普通用户事件带 admin 角色”由测试注入，用于模拟共享事件被错误赋值，不代表 QQ 用户可以直接控制框架内部字段。

## 尚需实际部署验证

没有使用用户的真实聊天平台、运行中的 AstrBot 服务或 Minecraft 服务端进行停服操作。部署后仍需检查：

- 适配器主动广播是否实际送达，尤其是其内部静默失败的情况。
- RCON、文件挂载、文件权限与真实玩家 UUID 体系。
- 实际 spark API、Java、核心及模组组合的兼容性。
- `stop` 后自动启动脚本是否运行，以及启动耗时是否在监控超时内。

“在线”只表示 RCON 查询可用，“重启成功”只表示新 RCON 连续通过就绪查询；不保证游戏端口或所有第三方业务模块都已完全就绪。测试缺少所需依赖时出现跳过项，应按实际输出记录，不能沿用上表的完整结果。
