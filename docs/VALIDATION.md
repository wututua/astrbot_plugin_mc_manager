# 验证结果

## v1.2.0 接口与版本验证

最低版本声明为 **AstrBot >=4.28.0,<5**，Python 3.12+。

| 正式发布包 | 自动测试 | 结果 |
|---|---|---|
| 4.28.0 | 151 项完整测试 | 全部通过，0 跳过 |
| 4.28.1 | 32 项适配层 + 10 项框架接口 + 8 项安装包测试 | 全部通过，0 跳过 |
| 4.28.2 | 32 项适配层 + 10 项框架接口 + 8 项安装包测试 | 全部通过，0 跳过 |
| 4.29.0 | 151 项完整测试 | 全部通过，0 跳过 |

检查范围包括插件公开导出、Star 基类和独立日志、生命周期、自定义过滤器、事件身份、群会话、主动广播、平台枚举、插件数据目录、异步配置保存、Web 请求/响应、后台鉴权、原生安装器和页面发现。配置保存被较新版本覆盖或请求取消的分支也做了回归。

实际 Web API 测试使用每个正式包自带的 astrbot.api.web 实现；4.29.0 的内部上传工具依赖也从该正式包载入。其余框架对象以测试替身提供。框架行为检查对目标包的原始方法进行隔离调用，不等同于运行完整 AstrBot 服务。

ZIP 同时包含 pages 和 views 两套相同静态文件：4.28 使用 pages，4.29 优先使用 views。安装测试调用目标版本的原始安装器、版本校验和页面发现逻辑，确认只发现一个 console 页面。

Ruff、Python 编译和 JavaScript 语法检查通过。发布包排除调研代码、数据库、测试依赖和缓存。

## 服务器释放与群号修改回归

- 15 项绑定专项测试：删除全部群释放服务器、同次提交转组、逐服移交、同平台群号修改、跨平台归属处理、旧广播清理、事务回滚、同配置重载、归档恢复、旧数据库迁移等。
- Web API 验证删除群后 bindings 中没有旧占用，服务器可以重新分配；原白名单与日志归档保留。
- 转给另一配置组的服务器不会自动从旧文件导入旧成员，新组条目同步后文件与新组一致。
- 群号修改保留白名单固定编号与同平台用户归属，旧日志记录原群号，广播会话及待发送消息清理。
- 跨平台修改会清空用户归属，匿名/普通成员不能操作无归属条目，管理员仍可管理。
- 迁移失败会恢复原配置、绑定和广播会话，并恢复原服务的同步循环。
- 浏览器确认群号可编辑，内部配置 ID 仍只读；删除群后在同一草稿中可选用释放的服务器。

## 配置错误修复回归

- 复现群模板缺少 id、platform_id、group_id 的加载错误，确认新版保留管理页面并标明具体缺失字段。
- 不完整群、重复 ID 和非法 servers 结构不会让配置修复接口失联；有效的群号修改现在直接迁移，不再当作加载错误。
- 修复状态下保持管理员鉴权，RCON 探测、白名单同步和重启操作暂停。
- 配置读取继续脱敏密码，并能读取原有历史绑定；失败保存保留原状态与版本标识。
- 正确配置保存后启动服务、清除错误提示，保留密码和历史数据。
- 真实官方 SDK 浏览器测试复现初始错误状态，验证自动打开配置页、编辑空白群、保存启用，以及历史身份字段恢复。

## 可视化网页配置

- 配置接口提供 schema、平台实例 ID/显示名称、历史绑定和配置版本标识，密码与平台令牌不泄露。
- 保存检查配置版本，过期页面不能覆盖其他页面的更新；错误保留当前服务和配置。
- 表单覆盖服务器目录/RCON/UUID/TPS、群聊平台/群号/服务器多选/管理员/条目上限、常规设置、指令、菜单、回复、广播和 spark 模板。
- 首次空配置通过浏览器表单完成添加服务器、绑定群、保存并刷新状态，全程没有编辑 JSON。
- 浏览器验证密码保留与显式清除、旧字段保留、草稿切换/状态刷新不丢失、重新载入确认、版本冲突、同时绑定冲突禁用，内部配置 ID 只读，群号和平台可编辑。
- 移除配置保留服务器文件与历史数据；有群引用的服务器拒绝直接移除。
- 高级 JSON 和表单可相互应用，无效 JSON 保留草稿并提示。

## spark 指标与本地采集器

- 用户提供的完整 spark 输出被解析为 19 个变量，逐个与样例值核对一致。
- 测试覆盖颜色、行前缀、CRLF、无换行、时间窗口/统计顺序变化、NaN、N/A、截断、额外数值、缺失区段、真实 0、模板变量校验及独立服务器输出。
- 本地数据来源测试覆盖 auto/file/rcon、文件缺失、数据过期、跨服路径、大小限制、未来时间和 API 未就绪。
- 可选 Java agent 使用实际 Java 8 JVM和与 spark 公共 API 形状一致的测试类进行验证，检查全部 19 个数值、私有实现类上的公开接口反射、原子写入与 daemon 退出。
- Agent JAR 仅含本项目采集代码；测试 SparkProvider 类不在 JAR 中。源码与说明位于 companion。
- 没有连接真实 MC 核心；Java agent 的真实 spark 版本、模组组合、权限和启动脚本需要用户部署后联调。

## 官方网页 SDK 浏览器验证

浏览器分别加载 **AstrBot 4.28.0** 与 **4.29.0** 正式发布包的 plugin_page_bridge.js，保留 SDK 自身的 ready/context 握手、api:get/api:post 请求和响应处理；测试父页面提供受控业务数据。

两版 SDK 均验证通过：

- 桌面 1280 × 1000、手机 390 × 844 和手机配置弹窗，无整体横向溢出。
- 群隔离、白名单增删改、日志筛选、服务器重启目标。
- 首次空配置的服务器/群表单、管理员列表、服务器多选、删除后的释放与重新绑定、可编辑群号。
- 密码保留与清除、别名、帮助菜单预览、回复与广播、spark 模板及变量表。
- 配置草稿、无效 JSON、多页面版本冲突、取消/确认和重新载入。
- 页面无未捕获 JavaScript 异常。
