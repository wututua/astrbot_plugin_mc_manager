# 版本记录

## v1.0.2

- 将兼容范围修正为 AstrBot >=4.26.3,<5，解决 4.26.3 被旧版本声明拦截的问题。
- 下载并检查 AstrBot 4.26.3 的正式发布包，确认插件使用的 Web API、过滤器、数据目录及管理页面 SDK 可用。
- 在 4.26.3 的原始版本检查方法中复现旧报错，验证新范围通过；同时保持对 4.28.2 的兼容。
- 导入与管理页面测试同时覆盖旧版 PluginUpdator 和新版 _PluginUpdater 的正式安装流程。
- AstrBot 4.26.3 对应的 68 项测试全部通过；4.28.2 的 17 项接口与安装包兼容测试也通过。

## v1.0.1

- 修复 metadata.yaml 缺少 AstrBot 必填字段 desc，导致 ZIP 上传后加载失败的问题。
- 打包前验证 name、desc、version、author 都是非空字符串，short_desc 不替代 desc。
- 检查元数据、pyproject.toml 和核心版本号一致，并自动生成对应版本的 ZIP 文件名。
- 添加 6 项安装包回归测试，包含实际 AstrBot 发布包的元数据检查和解压流程验证。

## v1.0.0

- 首次实现群服白名单管理、RCON 查询、重启监控、审计日志和管理页面。
- 此版 ZIP 缺少 desc 字段，请使用最新的 v1.0.2 安装包。
