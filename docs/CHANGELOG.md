# 版本记录

## v1.2.2

- 修复聊天入口直接信任管理员角色标记导致的归属权限绕过：全局管理员同时核对事件布尔身份和会话实际 `admins_id`，尊重 API Key 降权；配置不可核实时不授予全局权限。
- 本群 `admin_ids` 仍仅对本群生效；不自动授予 QQ 群主或群管理员服务器管理权限。
- 删除和修改的 SQL 写入条件包含条目所属用户；等待玩家 UUID 查询期间归属变化时拒绝写入。
- 拒绝缺少发送者身份的请求，拒绝将字符串或数字等非布尔标记作为管理员权限。
- 新增普通成员、误标管理员、编号/玩家名/自定义别名、其他群管理员、后台条目、空身份、配置异常、降权及归属变化等权限回归测试。

## v1.2.1

- 补充 @filter.command("mc") 原生注册，AstrBot 指令管理中可见 mc。
- 固定 /mc 和纯文本 mc 可唤起；自定义主指令作为别名统一进入同一个原生处理函数。
- 完整保留子指令和参数，避免双处理；禁用原生 mc 指令时所有别名一起停用。
- 使用正式发布包中的真实注册装饰器、命令过滤器、处理器注册表及 WakingCheckStage 验证触发流程。

## v1.2.0

- 当前服务器归属与历史数据分开，删除群绑定或取消勾选并保存后立即释放服务器。
- 允许编辑 QQ 群号和平台实例，保持内部配置 ID 固定。
- 同平台改群号保留白名单、编号与归属；跨平台改绑保留玩家、清空旧用户归属。
- 重置旧群广播会话，取消旧待发送通知，旧日志保留原群号。
- 服务器转给其他配置组后使用新组白名单，不自动导入旧组成员。
- 迁移旧数据库并清理旧版遗留占用，归档白名单与日志保留。
- 保存前暂停旧同步任务；数据库迁移失败时恢复原配置并继续原服务。

## v1.1.1

- 修复群模板未填完整就导致整个插件加载失败、网页无法编辑配置的问题。
- 配置不完整或历史绑定冲突时进入网页修复状态：保留管理员鉴权与配置页面，暂停服务器管理操作。
- 群绑定错误说明包含具体条目序号、缺失字段或重复 ID。
- 从修复状态保存正确配置后立即启动服务，保留原密码与历史归属。
- 已保存群缺失平台/群号时，表单从该群历史绑定恢复只读身份字段。
- 配置结构损坏仍能通过高级 JSON 修复，密码在修复页面中同样脱敏。

## v1.1.0

- 最低 AstrBot 版本升级为 4.28.0，版本范围为 >=4.28.0,<5。
- 核对 4.28.0、4.28.1、4.28.2 和 4.29.0 的正式发布包，覆盖插件使用的导出、事件、配置、生命周期、日志、平台、消息和网页接口。
- 使用 Star(context, config)、插件独立 self.logger、MessageChain.message 与 AstrBotConfig.save_config_async。
- 网页 API 在 initialize 成功后注册，卸载时只清理当前实例拥有的路由。
- 安装包从同一页面源码生成 pages 与 views 两套入口，新旧 SDK 名称均可用。
- 浏览器直接加载 4.28.0 与 4.29.0 的官方 SDK，验证握手、请求转发、配置和日常管理流程。
- 旧插件名称、配置结构和数据目录保留；从 4.26/4.27 更新时需要先升级 AstrBot。

## v1.0.4

- 管理页面新增可视化服务器、群聊、管理员、常规设置、指令、菜单、回复与广播表单。
- 添加群聊时选择真实平台实例，勾选本群服务器，并检查历史归属与 UUID 模式。
- 配置草稿切换页面不丢失，显式重新载入可放弃修改；高级 JSON 和 spark 模板编辑继续保留。
- 保存采用版本标识，拒绝过期页面覆盖新配置；密码可保留、更换或显式清除。
- 增加首次空配置、表单、历史绑定、草稿、冲突、手机布局与密码回归验证。

## v1.0.3

- spark TPS 输出拆为 19 个指标变量，支持自定义中文模板、缺失文字、提示与失败回复。
- 默认命令为 spark tps；提供完整默认配置和变量表，管理页面增加 TPS 模板编辑器与默认配置按钮。
- 针对 spark 异步命令的 RCON 空回复，附可选 Spark API Java agent，通过本地原子报告提供真实指标。
- 本地报告有路径隔离、大小和有效期检查，数据过期或未解析时不返回伪造数值。
